# Changelog

Notable **published** changes are tracked here. Local development features do not become available to users until a tested, tagged GitHub Release is published.

## [Unreleased]

- Repository documentation: privacy and security guidance, contributing instructions and issue/pull-request templates.
- v0.2.1 development is undergoing review. Planned features are described in the [roadmap](docs/ROADMAP.md), **not** in the current stable APK.

## [v0.2.0] — 2026-10-25

First stable multi-catalog release:

- Five independently downloadable offline catalogs: Anime, Manga, Movies, Series and Books.
- Simple and weighted detailed ratings, profile-based scoring, personal-taste bonuses and notes.
- Personal rankings with Top 3 podium, sorting, filtering and supported alternative-title search.
- Optional grouping of seasons, collections and variants.
- Themes, launcher icons, nine interface languages and optional artwork caching.
- Signed Android APK and five version-matched catalog pack assets published on GitHub Releases.

**Data safety:** deleting a pack **with its data** in v0.2.0 also removes the associated personal ratings/notes. See [PRIVACY.md](PRIVACY.md).
