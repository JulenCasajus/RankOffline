# RankOffline Roadmap

## Planned / Ideas

The following items are ideas for future work. They are not implemented yet and are not commitments for a specific release.

- Improve podium images and the podium visual design.
- Add filtering by themes and topics.
- Import or download user ratings from popular platforms.
- Add more languages.
- Expand RankOffline beyond anime:
  - manga
  - books
  - TV series
  - movies
  - video games
- Add a light theme; the app currently uses a dark theme.
