## Completed outside an emulator

- Python schema/integrity validation passes all five archives.
- The current Kotlin manifest, archive, item and group parsers accept every
  record and relation.
- A JVM harness using the actual filesystem `PackInstaller` installs each pack
  independently, verifies every payload SHA-256, parses the installed JSONL and
  commits its pending marker to READY.
- A second build produces identical archive SHA-256 values.
- All ten package backgrounds and both defaults have their required dimensions;
  each manifest declares separate Top 7 and Top 10 paths.
- The package formats and runtime archive readers were checked in isolation.
- The 197 Kotlin source files remain subject to the 12-function/500-line limits.
- Existing KSP output contains implementations for `RankOfflineDatabase`,
  `MediaDao`, `MediaCatalogDao`, `MediaGroupDao` and `PersonalDataDao`; the Room
  schema JSON is syntactically valid. It must still be regenerated by the next
  complete build.

Gradle and ADB cannot start inside the current managed environment because both
need local sockets. Therefore KSP regeneration, `assembleDebug` and emulator
behavior are not marked as passed here.

## Android Studio procedure

1. Sync the project, select Temurin JDK 25 and run:

   ```bash
   ./gradlew :app:clean :app:kspDebugKotlin :app:compileDebugKotlin :app:assembleDebug
   ./scripts/check-kotlin-limits.sh
   ```

2. Install `app/build/outputs/apk/debug/app-debug.apk` on an Android device.
3. Open RankOffline, refresh available packages, then download a package using
   the built-in package-management screen. Confirm the package reaches READY.
4. Force-stop, disable connectivity and reopen the app to verify offline use.
5. Repeat for all five packages, then with all five installed simultaneously.

## Emulator acceptance matrix

None of the following rows is considered passed until observed on the emulator.

| Area | Required check |
|---|---|
| Installation | Each pack reaches READY; cancellation leaves no visible partial pack; restart recovers a committed or pending import safely. |
| Catalog | First and later pages load; expected item/group counts are visible through diagnostics; no duplicate identities. |
| Search | Primary titles and known aliases resolve; clearing the query restores paging. |
| Filters | Every declared filter returns data and combines correctly with search/sort. |
| Merge/groups | Declared groups only, valid representative fallback and no cross-pack identity substitution. |
| Covers | All packs download through declared HTTPS hosts; Anime tries its pack-declared AniList source before the Jikan fallback and respects cancellation/rate limits. |
| Ratings | Simple/elaborate ratings and notes persist across restart; note/status-only edits preserve scores, profile, bonus and categories. |
| RankOfflineAll | Available only with participating packs READY; paging has no omissions/duplicates; Merge preference remains independent. |
| Share | Top 7 is 1080×1920, Top 10 is 1920×1080, correct package background is used, and All uses the supplied default backgrounds. |
| Backup | Export reports `schemaVersion=2`; global and partial restore preserve uninstalled-pack ratings and never replace unrelated packs. |
