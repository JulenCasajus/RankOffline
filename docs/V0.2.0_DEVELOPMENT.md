# v0.2.0 development notes

> **Unreleased, evolving development snapshot — 21 October 2026.** This document records the multi-media work before the next stable release; it does not imply these features are in v0.1.3 or already merged to `main`.

## Product expansion

- Five official downloadable/removable packs: **Anime, Manga, Movies, Series, Books**.
- Base APK separated from large production catalogs.
- First-run onboarding, optional pack download, per-pack progress and installed-size presentation.
- One shared pack install lifecycle: **Downloading → Verifying → Installing → Importing catalog → Preparing merge → Finalizing → READY**.
- Theme-aware navigation and settings, six built-in palettes and user-created color themes; rating modes/categories/profiles; app-icon choices.
- Nine UI locales.

## Infrastructure and correctness changes

- `schemaVersion: 1` data-only ZIP packs, strict archive/file size and SHA-256 verification, staging and atomic promotion/rollback.
- Plural official `PackId`s independent of legacy singular `MediaType` values.
- Pack lifecycle distinguishes installed files from Room/runtime READY; serialized recovery/install/purge per pack.
- Offline data snapshots imported once and reused as `NoChange` on restart.
- Precomputed Merge graph in each applicable pack; **no runtime relationship discovery on Merge tap**.
- Explicit relationships: Anime 2,196 groups / 6,685 memberships; Manga 206 / 428; Movies 2,156 / 6,371; Series 6,181 / 50,905 in the tested artifacts.
- Series groups use stable TMDB show IDs; Movies groups use explicit TMDB collection IDs.
- Grouped catalog results paginate in SQLite; rated-only group ranking avoids scanning all groups.
- Room schema v13 and non-destructive upgrades, including distinct item/group rating and cover identities.
- Cover viewer now waits for resolved Room observation instead of closing on the initial null; group covers query the group storage table.
- Ranking invalidation now includes rating/catalog revisions; failed rating saves surface an error.

## Measured emulator results (not guarantees)

These were measured on a Pixel 10 Pro emulator with local packs staged into private storage (no real network download). Times vary with hardware/storage.

| Pack | First import to READY, earlier | Later optimized |
|---|---:|---:|
| Anime | 81.9 s | **67.5 s** |
| Manga | 35.0 s | **29.7 s** |
| Series | 130.6 s | **120.3 s** |
| Movies | 136.4 s | **115.4 s** |
| Books | 122.8 s | **106.3 s** |

Follow-up logs showed generic catalog auxiliary genres/credits/alias inserts dominated the import time. Startup after import reused unchanged catalog/group metadata, although scanning/recovering all five packs still took time in that emulator.

Observed Merge SQL pages: ~0.31 s for 200 Series entries at offset 300 and ~0.18 s for Movies (earlier test); rated-group ranking sampled ~96 ms before / ~69 ms after for 58 candidates. These are isolated benchmark runs, not device-wide guarantees.

## Known unfinished work

- In-app third-party personal-pack import and management; only the shared format/registry groundwork exists.
- First-import auxiliary-table performance optimization.
- Real phone end-to-end regression of package downloads, remote cover fetching, rating persistence and post-restart behavior with the newest development build.
- Packaging/signing/publishing a fully matching next debug pre-release; prior debug assets must not be mixed with regenerated pack hashes.

## Release checklist

1. Validate the **actual local** APK and five pack/index SHA/size matches.
2. Build a new debug pre-release rather than relabel old assets.
3. Test install → READY → Merge → rating → downloaded cover → force-stop → reopen → pack deletion/reinstall.
4. Preserve stable v0.1.3; do not treat these development metrics as stable-release claims.
