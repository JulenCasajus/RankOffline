# 0.2.0 development status

RankOffline 0.2 is under stabilization and must not be published from an unmatched working tree.

Implemented locally:

- Room 14 with explicit stable-upgrade migrations and PackId-scoped personal ratings;
- one normalized `media_*` runtime for Anime, Manga, Movies, Series, and Books;
- data-only schema-1 packs, catalog format 1, and precomputed group format 2;
- per-pack recovery/readiness, strict validation, atomic replacement, and destructive purge;
- installed-only media selector plus package-management action;
- shared item/group rating, search, Merge, cover, and viewer behavior;
- four-color contrast-derived built-in/custom palette system.

The current local five-pack set and `category_pack_index.json` are matched, but existing published debug assets must be assumed incompatible until their hashes are explicitly compared. No artifact should be uploaded without the full migration, connected-test, manifest, and hash checklist passing as one release candidate.

Room 14 was introduced during unpublished development. Its structural schema is fixed by the exported schema file; changing it further requires a new explicit Room version. A same-version experimental database cannot be repaired by changing migration code after that migration already ran, so valuable development data must be backed up and assessed rather than reset.
